# App assets

All assets here are either generated for ModelView or open-licensed fonts.

- `fonts/Archivo-*.ttf`, `fonts/ArchivoNarrow-*.ttf` — Archivo family by
  Omnibus-Type, SIL Open Font License 1.1. The license text is `fonts/OFL.txt`.
  Downloaded from Google Fonts.
- `icon.png` — the ModelView mark, generated by `scripts/make_icon.py`.
  Synthetic; no third-party imagery.
- `samples/vase_broken.stl`, `samples/project.3mf` — synthetic sample geometry
  authored by `scripts/make_samples.py`. See the repository `samples/README.md`.
